# CRUD Frontend de Filmes

Aplicação web desenvolvida em **Next.js**, **React** e **TypeScript** para gerenciamento de filmes, consumindo uma API REST desenvolvida em Express.

## Funcionalidades

A aplicação permite:

* Listar todos os filmes cadastrados;
* Adicionar um novo filme;
* Editar as informações de um filme;
* Remover um filme;
* Exibir imagem, título e nota de cada filme.

## Tecnologias

* Next.js
* React
* TypeScript
* CSS
* Fetch API

## Estrutura

O frontend consome a API através dos seguintes endpoints:

```http
GET     /filmes
GET     /filmes/:id
POST    /filmes
PUT     /filmes/:id
DELETE  /filmes/:id
```
